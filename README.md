# Гарын дохио → Монгол текст

Вэб камераар гарын дохио таниад, дэлгэцэнд том монгол текст гаргадаг нэг файлт хэрэгсэл.
Илтгэл, цугларалт дээр ард талын дэлгэцэнд шууд гаргахад зориулагдсан.

Google MediaPipe-ийн гарын загвар дээр ажиллана. Сервер, бүртгэл шаардахгүй —
бүх боловсруулалт хөтөч дотроо хийгдэнэ, видео хаашаа ч илгээгдэхгүй.

## Юу чаддаг вэ

**Байрлал таних** — гарын хэлбэрийг таньж холбогдсон үгийг гаргана. Байрлал, зай,
гарын хэмжээнээс хамаарахгүй (бугуйгаар төвлүүлж, гарын хэмжээгээр масштабладаг).

**Хөдөлгөөн таних** — кадрын дарааллыг тогтоож, DTW (динамик цаг мушгилт) аргаар
тааруулна. Тиймээс хөдөлгөөнөө удаан ч, хурдан ч хийсэн, дэлгэцийн аль ч хэсэгт
хийсэн адилхан танина.

**Өөрөө зааж сургах** — ямар ч дохиог өөрийн үгтэй холбож болно. Заасан зүйл
хөтөчид хадгалагдаж, `.json` болгон гаргаж авах/сэргээх боломжтой.

**Бэлэн 8 дохио** — нэг алга, хоёр алга, эрхий дээш/доош, V, нударга, дээш заах,
хайрын тэмдэг. Гарах үгийг нь самбараас шууд засна.

**Хоёр гарын дохио** — нэг болон хоёр гарын дохиог тусад нь ялгана.

**⚡ Цахилгаан эффект** — хоёр алгаа нэг рүүгээ харуулахад хооронд нь цахилгаан
нум татна. Хүч нь алгануудын хоорондох зайгаар тодорхойлогдоно: ойртуулах тусам
хүчтэй, салаалсан, гэрэлтсэн болно. Зайг гарын хэмжээнд харьцуулж хэмждэг тул
камераас хол ойр зогссон нь нөлөөлөхгүй.

**🎞 Филтерийн хүрд** — хоёр гараа буулгахад 9 филтер төвөөс эргэлдэн гарч ирнэ.
Нэг гараа өргөөд хүссэн хөзөр рүүгээ заахад 0.9 секундын дотор сонгогдоно.
Хөзөр бүр дээр тухайн филтерээр шүүсэн амьд дүрс харагдана.

**Горим сонгох** — текст, цахилгаан хоёрын аль нэгийг нь эсвэл хоёуланг нь
ажиллуулна.

## Ажиллуулах

1. Багцыг татаж аваад нэг хавтсанд тавина
2. `ekhluuleh.ps1` дээр баруун товч → **Run with PowerShell**
3. Хөтөч нээгдэнэ → камерын зөвшөөрөлд **Allow** → **Камер асаах**

Зогсоохдоо PowerShell цонхон дээр Ctrl+C.

> **Файл дээр нь давхар дарж болохгүй.** `file://` хаяг дээр хөтөч камер болон
> загварын файлыг хоридог. Скрипт нь `http://localhost:8777` дээр жижиг сервер
> асааж, түүгээр дамжуулан нээдэг.

Эхний ачаалалтад ~2 MB-ын WASM файлыг CDN-ээс татдаг тул **интернэт хэрэгтэй**.
Загварын файл (`gesture_recognizer.task`, 8 MB) багцад орсон.

## Дохио заах

Баруун самбараас горимоо сонгоно:

| Горим | Хэзээ |
|---|---|
| ✋ **Байрлал** | Гарын тогтмол хэлбэр (алга дэлгэх, тоо үзүүлэх) |
| 🌀 **Хөдөлгөөн** | Замаар нь ялгагдах дохио (даллах, доош татах) |

Гарах үгээ бичээд **Бичих** дарна. 3 секунд тоолсны дараа 2.6 секунд бичнэ —
байрлалын үед гараа хөдөлгөөнгүй барина, хөдөлгөөний үед дохиогоо нэг удаа
бүтэн хийнэ. **Нэг үгэнд 2–3 удаа** давтаж зааж өгвөл мэдэгдэхүйц сайн танина.

Хөдөлгөөн **зогсолтоор төгсөх** ёстой — гар зогсмогц таслаж, тааруулна.

## Тохируулах

Танихгүй эсвэл андуурч байвал самбарын гулсууруудаар тааруулна:

- **Байрлалын мэдрэг** — бага = хатуу, андуурахгүй ч танихдаа татуу
- **Барих** — хэдэн кадр тогтвортой байхад үг гаргах вэ
- **Хөдөлгөөний мэдрэг** — хэр зөрүүтэй хөдөлгөөнийг зөвшөөрөх вэ
- **Эхлэх** — гар ямар хурдтай хөдлөхөд бичиж эхлэх вэ

Дээд самбарын «Танилт» дээр **хэмжсэн зөрүү тоогоор** гарна. Зөв хийж байгаа
атлаа танихгүй бол тэр тооноос арай өндөр болгож мэдрэгээ нэм.

## Товчлуур

| Товч | Үйлдэл |
|---|---|
| `F` | Бүтэн дэлгэц |
| `C` | Текст цэвэрлэх |
| `H` | Тохиргооны самбар нуух |
| `W` | Филтерийн хүрд нээх/хаах |
| `Esc` | Филтерийн хүрд хаах |
| `1` `2` `3` | Текст / Цахилгаан / Хоёулаа |

## Хязгаарлалт

Энэ бол **өөрөө зааж сургадаг прототип**, бэлэн орчуулагч биш.

Жинхэнэ дохионы хэл нь гарын хэлбэр, хөдөлгөөнөөс гадна нүүрний илэрхийлэл,
биеийн байрлал, дохионы дараалал гээд олон давхаргатай. Энэ хэрэгсэл зөвхөн
эхний хоёрыг нь — 21 цэгээр илэрхийлэгдэх гарын хэлбэр, бугуйн замыг — ажиглана.
Хэдэн арван дохио цээжлүүлж, тодорхой хэрэглээнд (илтгэлийн товчлол, энгийн
мэндчилгээ) ашиглахад тохиромжтой.

Хоёр гарын дохионы үед хоёр гар хоёулаа кадрт бүтэн харагдаж байх шаардлагатай.

## Техник

- [MediaPipe Tasks Vision](https://ai.google.dev/edge/mediapipe/solutions/vision/gesture_recognizer) — гарын 21 цэг, бэлэн дохионы ангилагч
- Байрлал таних — хамгийн ойрын хөршийн арга, нормчилсон 42 хэмжээст вектор дээр
- Хөдөлгөөн таних — 16 кадрт жигдрүүлсэн дараалал дээрх DTW
- Зависимост байхгүй, нэг HTML файл, build хийх шаардлагагүй
